# Quick Start Guide

## 🚀 Get Started in 3 Steps

### 1. Navigate to the project
```bash
cd upright-systems
```

### 2. Start the development server
```bash
npm run dev
```

### 3. Open your browser
Visit [http://localhost:3000](http://localhost:3000)

That's it! The website is now running locally.

## 📝 Next Steps

### Customize Content
1. **Hero Section** - Edit `components/sections/hero.tsx`
2. **About Section** - Update milestones in `components/sections/about.tsx`
3. **Services** - Modify services in `components/sections/services.tsx`
4. **Contact Info** - Update details in `components/sections/contact.tsx` and `components/footer.tsx`

### Update Colors
Edit `app/globals.css` to change the blue/yellow color scheme.

### Connect Contact Form
Update the `onSubmit` function in `components/sections/contact.tsx` to connect to your backend or email service.

✅ Smooth scroll navigation
✅ Form validation with React Hook Form + Zod

- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form + Zod
- next-themes
